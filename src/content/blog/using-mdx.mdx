主题默认包含了 [@astrojs/mdx](https://docs.astro.build/en/guides/integrations-guide/mdx/) 集成。

## 为什么使用 MDX？

MDX 是一种特殊的 Markdown 版本，支持嵌入 JavaScript 和 JSX 语法。这使得你能够 [将 JavaScript 和 UI 组件混合到你的 Markdown 内容中](https://docs.astro.build/en/guides/integrations-guide/mdx/#mdx-in-astro)，用于诸如交互式图表或警示等功能。

如果你已经有用 MDX 编写的现有内容，这个集成希望能使迁移到 Astro 变得非常轻松。

## 示例

以下是如何在 MDX 中导入和使用 UI 组件。
当你在浏览器中打开此页面时，你应该会看到下面可以点击的按钮。

import HeaderLink from '../../components/HeaderLink.astro';

<HeaderLink href="#" onclick="alert('clicked!')">
	MDX中的嵌入组件
</HeaderLink>
